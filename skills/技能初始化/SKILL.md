# 技能初始化

配置当前项目以便其他技能可以正常工作。

## 流程

1. 询问用户要使用的 Issue 跟踪器类型（GitHub / Linear / 本地文件）
2. 询问用户在分类 Issue 时使用的标签体系
3. 询问用户希望保存文档的位置


## 输入要求
- 项目仓库路径（或 Issue 跟踪器 URL）
- 目标 Issue 跟踪器类型（GitHub/GitLab/Linear/本地文件）

## 执行流程
1. 读取项目现有配置、标签体系和文档约定
2. 设计分类标签映射、Issue 模板和里程碑
3. 确定文档目录布局（CONTEXT.md、ADR、docs/）
4. 展示完整方案并等待用户确认
5. 执行配置写入并验证

## 异常处理
- 已有标签体系时增量补充而非覆盖
- 目标平台不可访问时输出离线配置方案

## 交付产物
- 已配置的标签、模板和里程碑清单
- 分类规则文档
- 文档目录结构和布局约定

## 配置完成后

- Issue 跟踪器类型已记录
- 分类标签映射已建立
- 文档目录结构已确定

## 用户确认门
创建或修改 Issue 标签、项目配置、工作流及文档布局前，先展示拟变更清单、作用域和回退方式并等待用户确认。
