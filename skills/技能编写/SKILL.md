# 技能编写

## 执行流程
1. 明确技能的目标场景和边界（做什么、不做什么）
2. 设计技能的输入要求、执行步骤、交付产物和状态模型
3. 编写 YAML front matter 和 Markdown 正文
4. 交叉检查与已有技能的路由引用一致性
5. 用实际场景验证技能能否指导 AI 完成端到端任务

## 异常处理
- 新技能与已有技能职责重叠时明确差异或建议合并
- 引用不存在的技能名时标注为路由错误

## 交付产物
- 完整的 SKILL.md 文件
- 交叉引用一致性检查结果
- 示例场景验证记录

技能的存在的意义是从随机系统中提取确定性。**可预测性** — Agent 每次运行走_相同的过程_ — 是根本美德。

## 核心概念

### 调用方式
- **模型触发** — Agent 可自主调用。设置 `description`（含触发短语）。占用上下文负载。
- **用户触发** — 只有手动输入可调用。设置 `disable-model-invocation: true`。零上下文负载，但增加认知负载。

### 信息层次
技能内容分为**步骤**和**参考**。信息层次决定内容位置：
1. **技能内步骤** — SKILL.md 中的有序操作。每步以完成标准结束。
2. **技能内参考** — SKILL.md 中的定义/规则/事实，按需查阅。
3. **外部参考** — 推出到单独文件的内容，通过上下文指针触发加载。

### 何时拆分
- **按调用拆分** — 有独立的触发词时创建新模型触发技能
- **按顺序拆分** — 后续步骤诱使 Agent 仓促完成当前步骤时拆分

### 核心词汇
- **前置词** — 模型预训练中已有的紧凑概念（如_课程_、_迷雾_、_tracer bullet_）
- **完成标准** — 告诉 Agent 工作完成的_可检查_条件
- **同源唯一真实来源** — 每个含义一个权威位置
- **渐进式揭示** — 从 SKILL.md 推出到链接文件

### 反模式
- **提前完成** — 步骤未真正完成就收尾。防御：锐化完成标准
- **重复** — 同一含义在多个位置出现
- **沉积** — 陈旧层次堆积
- **蔓延** — 技能太长。治疗：通过指针揭示参考内容
- **空操作** — Agent 无需该指令也会默认执行的语句
