# 资源占用优化

## 适用范围

减少应用/服务在**运行时**的资源消耗与占用，覆盖六个维度：

- 内存：占用峰值、泄漏、缓存策略、大对象
- CPU：无谓计算、轮询、GC 压力、主线程负载
- 电量：唤醒、传感器、定位、后台任务、Doze 适配
- 网络：请求次数、流量、缓存、压缩
- 磁盘 / IO：写放大、日志、数据库、缓存目录
- 后台行为：保活治理、定时任务、广播与服务

触发信号词：内存占用高、电量消耗快、减少资源占用、资源瘦身、内存泄漏、省电优化、流量用太多、后台耗电、运行很卡还费电。

不适用（应转交）：延迟 / 吞吐量瓶颈定位 → **性能分析与优化**；依赖版本选择 → **依赖升级与技术债治理**；模块结构问题 → **模块化分析**。

## 判定标准

### 测量优先原则

- 任何优化**必须**以可重复的测量为起点：先量化"现在占用多少"，再谈优化
- 未经测量的"优化"视为随机修改；不优化无法验证收益的假设问题
- 优化前后用**相同的环境与方法**测量对比，单一变量变更

### 各维度常见问题点（命中即疑似项，需测量证实）

**内存**
- 泄漏：静态持有 Activity/Context、长生命周期持有短生命周期对象、监听器/回调未注销、Handler/协程未取消、单例持有 View
- 大对象：全尺寸 Bitmap、未缩放图片、大集合、重复创建对象
- 缓存：无缓存策略或缓存无限增长、LRU 缺失、`onTrimMemory` 未处理

**CPU**
- 无谓轮询（Timer/while+sleep 替代事件驱动）、频繁 GC、主线程做重活
- 动画常驻（屏幕不可见仍运行）、后台计算无节制、过度序列化/反射

**电量**
- 唤醒锁未释放/长时间持有、GPS/传感器常开不关
- 高频后台任务、未适配 Doze/App Standby、网络同步过频、定位精度过高

**网络**
- 请求冗余（重复请求、无合并）、无缓存或缓存失效策略不当
- 未压缩传输、图片未按需裁剪、轮询代替推送

**磁盘 / IO**
- 高频小写入（日志、偏好、数据库）、无批量事务、索引缺失
- 日志级别生产环境过重、缓存目录无限增长不清理、重复读文件

**后台行为**
- 无意义保活、常驻前台服务无必要、Broadcast 过频、WorkManager 未用约束条件

### 优化取舍标准

- 优化**不得改变可观察行为**与正确性；优化前后必须通过相同功能测试
- 在资源收益与复杂度/可维护性间平衡：不做"为省 1KB 内存牺牲可读性"的过度优化
- 涉及系统级行为（权限、保活、后台策略、数据删除）的变更需用户确认

## 执行流程

1. **明确目标与基线**：确定当前资源占用基线（内存峰值/常驻、CPU 占比、电量占比、流量、磁盘），与用户确认优化目标（"降到什么程度"）
2. **测量与识别**：使用 profiler / dumpsys / 流量统计 / 电量统计等工具量化各维度占用，列出"占用大 × 发生频繁 × 用户可感知"的候选项
3. **分类与排序**：按影响（占用 × 频率 × 感知）与改动成本排序，先做高收益低成本项；区分"快速修复"与"结构性改造"
4. **单一变更实施**：一次只改一个候选项，优先最小充分方案（如先降分辨率/加缓存/改监听注销，不先大改架构）
5. **验证与对比**：同环境重测，与基线对比；未达预期或引入回归则回滚；验证功能测试通过
6. **固化与防护**：将有效优化固化，补充回归防护（性能测试、lint 规则、监控指标），防止回退

## 边界

- **测量优于猜测**：没有基线数据不宣称"优化了"；不优化未测量的假设问题
- **正确性优先**：任何优化不得改变可观察行为，功能测试必须通过
- **不过度优化**：在资源收益与代码复杂度/可维护性之间取平衡，尊重用户可接受成本
- **确认门**：涉及权限、保活策略、后台行为、数据删除、系统级配置的变更，先说明影响与回退方式并等待确认
- **不做黑科技**：不使用非正规保活/清理手段（如隐藏前台服务、频繁自启），遵守平台后台限制规范
- **与性能技能分工**：延迟/吞吐瓶颈定位与基准对比 → **性能分析与优化**；资源占用面的识别与削减 → 本技能；两技能结论冲突时以测量证据为准
- **决策留痕**：优化项、基线数据、变更与验证结果记录在案（迭代日志），便于回溯

## 期望输出

每次优化交付包含：

1. **资源基线**：优化前各维度占用数据（内存/CPU/电量/网络/磁盘）
2. **候选清单**：识别出的占用项 + 影响排序 + 改动成本
3. **实施记录**：每项单一变更（改了什么、为何、如何验证）
4. **对比结果**：优化后同环境重测数据，与基线对比（收益 / 无收益 / 回滚）
5. **防护措施**：新增的回归测试 / lint 规则 / 监控指标
6. **遗留项**：未处理的候选项与原因

汇报格式：基线 → 候选排序 → 已实施变更与验证 → 对比结果 → 防护与遗留。
