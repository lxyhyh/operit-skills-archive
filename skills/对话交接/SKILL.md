# 对话交接


## 输入要求
- 当前对话的完整上下文（自动从会话历史提取）
- 用户指定的下一会话焦点（可选）

## 执行流程
1. 提取对话中的决策、待办、风险和技术上下文
2. 扫描已有文档（PRD、ADR、Issue）避免重复
3. 脱敏敏感信息（密钥、密码、令牌等）
4. 生成结构化交接文档并保存到临时目录
5. 建议新会话应调用的主技能和备选技能

## 输出格式
- 当前状态：已完成/进行中/已阻塞的任务
- 已做出的决策和理由（附证据和风险）
- 待办事项（带优先级和依赖）
- 技术上下文（仓库、分支、环境）
- 风险清单（残余风险和缓解措施）
- 建议技能（供新 Agent 调用）

## 异常处理
- 如果对话中没有明确决策或待办，标注"当前无明显未决事项"
- 如果检测到敏感信息无法完全脱敏，标注风险并建议用户手动审查

## 交付产物
- 交接文档文件（Markdown 格式，保存路径明确告知用户）
- 建议技能列表及调用顺序

## 状态模型
每项工作汇报状态：已完成 / 部分完成 / 已阻塞。
"已完成"要求交接文档已保存且用户可访问；"部分完成"说明哪些内容因信息不足未包含。

将当前对话总结成交接文档，使全新的 AI 可以继续工作。保存到操作系统临时目录 - 不是当前工作空间。

## 要求

1. 在文档中包含"建议技能"部分，建议新会话应调用的技能
2. **不要**重复已在其他工件（PRD、计划、ADR、Issue、commit、diff）中捕获的内容 — 通过路径或 URL 引用它们
3. 脱敏敏感信息（API key、密码、个人身份信息）
4. 如果用户传了参数，将其视为下一会话焦点描述，并相应调整文档
