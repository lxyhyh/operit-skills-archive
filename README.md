## Archive Scope

- 归档范围：`/sdcard/Download/Operit/skills/` 下的 57 个顶层 Skill 目录中的 `SKILL.md`。
- 存放位置：`skills/<Skill 名称>.md`；文件名保留本地 Skill 原名称。
